# Unbroken · 键盘一笔画

一条不能断的线，走完键盘上的每一个键。

整个网站只有一块 3D 机械键盘（Three.js），它在每一屏扮演不同的角色：
首页里是背景和乐器，关卡里是棋盘，过关时是一张笔迹图，终局是一座十二层的塔，
音乐模式里是一件有二十四种音色的乐器。

## 运行

```bash
npm install
cp .env.example .env   # 填上 DeepSeek API key（过关时的那句话由它来写）
npm start              # 打开 http://localhost:3000
```

macOS 上也可以双击 `启动游戏.command`。

## 玩法

- 只能走上下左右紧挨着的键，每个键只能踩一次，把亮着的键全部走完。
- 一共 12 关，从 5 个键走到 40 个键；第 11 关加进数字排，第 12 关连 `; , . /` 一起。
- 第 8 关起必须停在指定的终点键上。
- **提示**（`Enter`）：告诉你下一步走哪；已经走进死路的话，告诉你退回到第几步，再按一次直接帮你退。
- **跳过本关**：点两下确认，自动代走一遍；最后的塔里这一层会是一道虚影。
- 过关后，AI 用这一关的字母写一句话；句子里每个词的首字母会从 3D 键盘上飞起来落进句子。

## 音乐模式

| 按键 | 作用 |
|---|---|
| 四排字母 / 数字键 | 琴键：往右高一级，往上高一个八度，A 那一排是中央八度 |
| `F1`–`F12` | 选乐器；`Caps Lock` 在 A / B 两组之间切换（共 24 件） |
| `←` `→`（或 `-` `=`） | 降调 / 升调（半音） |
| `↑` `↓` | 高八度 / 低八度 |
| `Shift` / `Option(Alt)` + 键 | 临时升 / 降半音 |
| 空格 / `Enter` | 延音踏板（按住 / 开关） |
| `Esc` | 返回 |

- **曲库**：内置 9 首（含《后来的我们》《步步》的主歌和副歌），可以试听、跟弹、编辑、保存自己的曲子。
- **导入乐谱**：简谱文本（`.txt`）、MIDI（`.mid`）、MusicXML（`.musicxml` / `.xml`），导进来直接演奏；也可以把文件直接拖进页面。
- **听歌识曲**：对着麦克风哼、唱或者弹一段，从曲库里认出是哪一首；认不出来的也能存成新曲子。只在本机分析，不上传。

### 简谱记法

```
1–7 音级   0 休止   ^ _ 高/低八度   # b 升/降半音
-  延长一拍   /  时值减半   .  附点   |  小节线
( ) 圆滑线   ~ 延音线（同音连成一个长音）   { } 三连音
```

例：`(5 3/) 3/ ~ 3 0/. 2// | {1 2 3} 5 - -`

## 风格

顶栏的调色盘按钮：

- **情绪**（开心 / 悲伤 / 放松 / 紧张 / 忧郁 / 自由）：换音阶和灯光。音乐模式里整块键盘会换成对应的调式，比如悲伤是自然小调。
- **场景**（爱情 / 失恋 / 冒险 / 梦想 / 自然 / 城市 / 海洋 / 日落）：换键帽配色、背景粒子和环境声。
- **声音与画面**：混响（房间 / 大厅 / 教堂）、回声、画风（清澈 / 温暖 / 明亮 / 复古），以及氛围感、空间感、电影感、环境声几个开关。

## 目录

```
server.js              Express 服务 + AI 造句接口（/api/generate）
public/index.html      页面结构
public/style.css       样式（颜色全部跟着当前键帽配色走）
public/script.js       游戏、音乐模式、风格、导入、听歌识曲
public/js/kb3d.js      3D 键盘引擎（按需渲染、自适应分辨率）
public/js/audio.js     24 件合成乐器 + 效果链 + 场景环境声
public/js/colorways.js 33 套键帽配色
public/vendor/three/   Three.js r186（本地一份，不依赖 CDN）
```

需要支持 WebGL 的浏览器（新版 Chrome / Safari / Edge / Firefox）。
