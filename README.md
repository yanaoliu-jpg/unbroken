# Unbroken · 键盘一笔画

一条不能断的线，走完键盘上的每一个键。

整个网站只有一块 3D 机械键盘（Three.js），它在每一屏扮演不同的角色：
首页里是背景和乐器，关卡里是棋盘，过关时是一场梦，终局是一座十四层的塔，
音乐模式里是一件有二十四种音色的乐器——还能整块沉进一只发光的水箱里弹。

## 运行

```bash
npm install
cp .env.example .env   # 填上 DeepSeek API key（过关时的那句话由它来写）
npm start              # 打开 http://localhost:3000
```

macOS 上也可以双击 `启动游戏.command`。

**在线版**：https://yanaoliu-jpg.github.io/unbroken/ ——GitHub Pages，每次推送到 `main` 自动把 `public/` 发布上去（`.github/workflows/pages.yml`）。
那里只有静态文件：键盘、关卡、音乐模式、深海、钢琴录音都能用；过关的句子要 `server.js` 和 DeepSeek key，在线版没有，会自动改用本地词库拼一句。

## 玩法

- 只能走上下左右紧挨着的键，每个键只能踩一次，把亮着的键全部走完。
- 一共 14 关，从 5 个键走到 40 个键；第 11 关加进数字排，第 12 关连 `; , . /` 一起。
- 第 8 关起必须停在指定的终点键上（终点要留到最后一步）。
- **第 13 关**：起点、终点都定死——F 和 T 斜对着，只差一步，却得绕完整块键盘才能回来（一共只有三种走法）。
- **第 14 关**：从 Q 出发，按顺序经过 W → O → R → L → D，最后停在 D 上。四十个键，只有一种走法。
- **提示**（`Enter`）：告诉你下一步走哪；已经走进死路的话，告诉你退回到第几步，再按一次直接帮你退。
- **跳过本关**：点两下确认，自动代走一遍；最后的塔里这一层会是一道虚影。

### 过关仪式：一场梦

1. **入梦**：最后一步落下，键盘的灯暗下去、光留下来——走过的线变成霓虹，页面背后浮出星云、星星和慢慢往上飘的光斑，
   偶尔划过一颗流星；音符后面拖出很长的尾音。
2. **彗星**：一颗亮点顺着整条线从起点跑到终点，一路撒星尘；经过哪个键，哪个键响一声、升起一道细光。镜头压低、跟着它慢慢摇过去。
3. **超新星**：到终点炸开——一团星尘、两圈彩虹色的冲击波荡满整块键盘，底下升起几枚星光烟花。
4. **浮起**：过关页上笔迹重新画一遍（笔尖撒着星星），然后整条离开键盘悬在上面，像萤火一样一直往外冒星点。
5. **拾字**：AI 写的那句话先只露出影子，每个词的首字母是一颗发光的光球，挂在它那颗键的上方——
   按下它（或者点它），键里升起一道光，字母拖着星尘飞回句子里，一个字母一个音。`空格` 全部放飞，`Enter` 直接下一关。
6. **成句**：整条线"呼"出一口星星，一道彩虹光扫过整句话，收一个和弦。

画面是一套只在仪式里才搭起来的后期：泛光 + 柔焦 + 一点色散，星尘是 GPU 粒子（运动全在着色器里算）；
浅色的键盘会压得更深，发光的线才显得出来。离开过关页后后期自己拆掉，平时的渲染一点不多花。
系统开了"减少动态效果"时整场梦都不演，只留最朴素的版本。

## 音乐模式

| 按键 | 作用 |
|---|---|
| 四排字母 / 数字键 | 琴键：往右高一级，往上高一个八度，A 那一排是中央八度 |
| `F1`–`F12` | 选乐器；`Caps Lock` 在 A / B 两组之间切换（共 24 件，A 组的 `F9` 是小号） |
| `←` `→`（或 `-` `=`） | 降调 / 升调（半音） |
| `↑` `↓` | 高八度 / 低八度 |
| `Shift` / `Option(Alt)` + 键 | 临时升 / 降半音 |
| 空格 / `Enter` | 延音踏板（按住 / 开关） |
| `Esc` | 返回（在深海里是浮上来） |
| `Tab` | 在深海里换一种水（深海 / 火山 / 冰川 / 田园），`Shift+Tab` 往回 |

- **曲库**：内置 7 首，可以试听、跟弹、编辑、保存自己的曲子（自己存的曲子在浏览器里，不会丢）。
- **换乐器的过场**：点乐器或按 F 键，整块键盘的键帽从左上角开始一道波似的飘起来——歪着悬一下，
  升到最高处换上新乐器的颜色（底下的灯把露出来的白色轴体和十字轴心照亮），再落回轴上"咔哒"一顿。
  镜头同时从正前方转到斜侧、再转回来；键帽升起时新乐器弹 do mi sol do，落下时一串很轻的"咔哒"。两秒左右。
  一弹琴或者再换乐器就立刻落下收场；连着快速换乐器时不飘，直接换。
- **键帽配色**（乐器那一排右边）：原色、同色渐变（用这件乐器配色里的渐变铺满整块键盘）、海洋、日落、樱花、彩虹——
  字母键取渐变上自己那个位置的颜色，功能键深一截，强调键用点缀色，每颗键上的字按键帽深浅自动挑深色或浅色。
- **钢琴**：真三角琴的录音——Salamander Grand Piano V3（一台 Yamaha C5，话筒架在琴弦上方十来厘米，近距离收音；[来源和授权](#钢琴录音)）。
  - 每隔小三度录了一个音（A0 到 C8 共 30 个），其余的音变速播放，最多偏一个半音；
  - **四档力度**是真的敲了四次（弱 / 中弱 / 中强 / 强）：重的那一下泛音多得多、更亮，不只是更响。档与档之间再用一点高频的提 / 压和音量接上，
    轻重是连续的；每个音都按离线量好的响度对齐过，弹音阶时相邻两个音不会一个响一个轻；
  - 松手是制音器落下：先很快地一收，剩一点余振再慢慢没掉（0.3–0.9 秒，低音弦长些；F6 以上本来就没有制音器，按自己的余音响完），
    同时有一下录下来的**松键声**（键弹回来、琴槌落回去）；
  - **延音踏板**（空格按住 / `Enter` 锁住）：踩着的时候松手不落制音器，音按录音里十几秒的长余音响完；踏板本身也有声音（踩下去"嗡"、抬起来"咔"），
    琴房和混响也会"开"一点（模拟没弹的弦跟着共鸣）；
  - 外加一间小**琴房**的卷积（1.1 秒、早期反射密、高频先衰减）：只有琴房时湿声占钢琴总能量的 15%，加上默认的大厅混响一共约 17.5%；
  - 录音按需去取：一进音乐模式先取这一屏会弹到的音（中间的八度最先），乐器名下面有一条细细的进度，取完说一声"就绪"；
    还没取到的音先用实时合成的钢琴顶上，第一下按键不会没声音。整套录音取不到时，退回原来那套物理建模的钢琴。
- **触键**（乐器那一排右边）：轻柔 / 适中 / 有力。电脑键盘没有力度感应，力度由档位定一个基准，再按弹的样子微微起伏——
  几乎同时按下的和弦一样重、连得很快的经过音轻一点、停一会儿再弹的第一个音重一点、同一个键连敲后一下轻一点，外加 ±5% 以内的随机，
  同一个音连弹两下不会一模一样。钢琴的三档各自落在一档录音上：轻柔的柔、暗，有力的响、亮（按下的键荡开的涟漪也跟着轻重走）。
  试听曲子时强拍重一点、长音稍重、短的经过音稍轻。
- **小号**：铜管——两根锯齿波进一个"起音时从暗一下子打开"的滤波器，并联三处号管的共振，起音的音高从偏低一点滑上来。
  它替掉了原来的"合成拨弦"（那件和吉他、竖琴像到 97–98%，耳朵几乎分不出来；第 11 关还用它）。
- **深海模式**（音乐模式右上角，或菜单里）：键盘沉进一只玻璃水箱——黑色背景，按下的键里升起荧光的气泡和烟雾，
  一根根光柱往上长，头顶是会起涟漪、会反光的水面，键帽和箱底上晃着焦散的光纹，最后过一遍泛光、折射、色散、暗角、颗粒。
  - **四种水**（`Tab` 换下一种，或点控制栏的「风格」）：深海、火山（岩浆湖：火星往上窜、箱底是岩浆的裂缝）、
    冰川（冰下的水：白色的泡、下着雪）、田园（阳光照进的清水塘：花粉和萤火、金色的光柱）。
    水色、背景、灯带、光柱、粒子、箱底、调色、环境声、按键时的小声响各不相同，换的时候颜色慢慢过渡过去。
  - **自己挑颜色**：键盘、背景、棱柱（水箱棱上的灯带）三个颜色，每种水各记各的；「还原」回到这一种水原来的样子。
  - **看得见字母**：进到水箱里，键帽一排比一排高（像一道台阶），每个琴键正面刻着字母和音级（Q ^1、A 1、Z _1……），
    隔着前壁平视也知道哪个键是哪个音；F 键那一排正面刻着乐器名。
  - **环境声音量**：面板里单独调，每种水各记各的。

### 简谱记法

```
1–7 音级   0 休止   ^ _ 高/低八度   # b 升/降半音
-  延长一拍   /  时值减半   .  附点   |  小节线
( ) 圆滑线   ~ 延音线（同音连成一个长音）   { } 三连音
```

例：`(5 3/) 3/ ~ 3 0/. 2// | {1 2 3} 5 - -`

## 风格

顶栏的调色盘按钮：

- **情绪**（开心 / 悲伤 / 放松 / 紧张 / 忧郁 / 自由）：换音阶和灯光。音乐模式里整块键盘会换成对应的调式，比如悲伤是自然小调。
- **场景**（爱情 / 失恋 / 冒险 / 梦想 / 自然 / 城市 / 海洋 / 日落）：换键帽配色、背景粒子和环境声。
- **声音与画面**：混响、回声、画风（清澈 / 温暖 / 明亮 / 复古），以及氛围感、空间感、电影感、环境声、流光几个开关。
  混响分房间、大厅、教堂三种空间，一听就分得出来。钢琴自己还带一间小琴房（见音乐模式），所以钢琴送进这里的混响比别的乐器少一点。
- **环境声音量**：选了带环境声的场景（雨、海浪、林间……）之后，面板底下那根滑杆调它的大小，每个场景各记各的；
  九种环境声已经按响度对齐过，换场景时背景声不会忽大忽小。
- **渐变**：每套配色都有一条渐变——键帽底光从左下铺到右上，走线从起点到终点顺着它换颜色，背景里有一圈同色的极光；
  打开「流光」，这些颜色会慢慢流动。
- **每套配色的场景**：键盘背后有一幅属于这套配色的背景画——青岚的雾中青山、晨光和破晓的日出、霜夜的弯月、极光和苔原的极光帘、
  海雾和加勒比的海平线、朱砂（古筝）的水墨山和红日、竹青（长笛）的竹林、教堂（管风琴）的彩窗、掌机（8-bit）的像素风景、
  巴黎（手风琴）带铁塔的天际线、霓虹和流光的合成波网格、星辰 / 星云 / 寰宇的银河、钢琴和小号的舞台追光……一共十八种画法；
  空中还飘着各自的东西（雪、灯下的浮尘、落叶、音符、像素、星芒……），镜头前偶尔飘过几颗很虚的大光斑（景深）；
  外壳正面有一块刻着配色名字的铭牌。选了"场景"的话，场景的粒子优先。
- **测一下声音**：弹一个和弦，从送往扬声器的那一路量电平，告诉你是浏览器把音频挂起了、音量是 0，还是一切正常。

## 声音检测

打开 `http://localhost:3000/soundcheck.html`：

- **实时自检**：输出电平表 + 音频状态。
- **响度平衡**：每件乐器离线渲染三种弹法，按 ITU-R BS.1770 量 LUFS。二十四件乐器已经按这个校准过（`js/audio.js` 里的 `LOUDNESS_TRIM`；
  钢琴换成真钢琴录音之后又量过一次，和其余乐器的中位数差 0.04dB）。
- **频谱**：任意一件乐器、任意一种弹法画成频谱图。
- **像不像**：用 MFCC 和起音 / 衰减 / 亮度比较每两件乐器的音色。
- **延迟**：浏览器报的各段延迟（网页 + 限幅器 + 浏览器缓冲 + 系统和耳机），插拔耳机会自动刷新；
  再加一个"跟着节拍按空格"的实测——有线耳机测一次、蓝牙耳机测一次，两次的差就是蓝牙多出来的延迟。

### 耳机和延迟

从按下键到听见声音，网页自己只占不到 1 ms，限幅器固定 6 ms，浏览器缓冲几毫秒；剩下的全在系统和耳机：
外放、有线耳机一般加起来 30–50 ms，蓝牙耳机常常 150–300 ms——这是蓝牙本身的，网页没法让它变快。所以：

- 自动播放的东西（试听、深海演示、过关回放）会按测到的延迟让画面等一等，看到的和听到的对得上；
- 手上弹的没法让声音提前，检测到延迟明显偏大（多半是蓝牙）时会提示一次；想弹琴跟手，用有线耳机或外放。

### 性能

- **按需渲染**：画面没变化就不画；只有呼吸、流光、光点慢慢流这类缓慢的动时按 30 帧画（肉眼看不出差别），按键、镜头、粒子一动就回到 60 帧。
- **实例化**：走线、塔的每一层都是 4 次绘制（段芯 / 段光壳 / 关节芯 / 关节光壳），和线多长无关——终局那座塔从每帧约 1400 次绘制降到约 300 次。
- **后期只在需要时搭**：梦境、深海的泛光管线平时不存在。
- **着色器提前编好**：页面空闲下来后，把梦境和深海要用的着色器在后台先编一遍——第一次换乐器、第一次过关、第一次进深海时
  不会因为现编着色器卡一下（实测第一次进深海要现编的程序从 19 个降到 0 个）。
- **自适应分辨率**：帧率跟不上就降一档像素密度，长时间很顺再升回来。
- **钢琴录音**：一个音是两个采样播放节点，弹得再密也不费劲。录音按需去取（进音乐模式先取这一屏、当前触键那一档，约 3–4MB），
  解码后的整理在后台线程里做；前 2.5 秒原样存、之后的余音降一半采样率存（听不出差别：接缝处和原录音的误差在 -50dB），
  一屏一档力度解码后约 50–60MB，总共不超过 180MB（手机 72MB），超了先扔最久没弹过的。
- **背景画缓存**：最近画过的几张背景画留着，来回换乐器不用每次重画。
- **传输**：服务端把 js / css / html 压缩后缓存在内存里（three.js 两个文件约 750KB → 不到 200KB）；
  three.js 和字体让浏览器存一天，自己写的代码每次都回来确认一下有没有更新（没变就是一个 304）；
  页面一打开就把所有模块一起去要，不再一层等一层。

`/api/generate` 只收 1–12 个英文字母；同一个地址每分钟最多 30 次（超了用本地词库拼一句）；DeepSeek 20 秒不回就用兜底句。
放到公网上时，DeepSeek key 只在服务端的 `.env` 里，不会发到浏览器。
自测时在地址后面加 `?debug`，内部状态会挂到 `window.__ub` 上。
