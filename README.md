# Unbroken · 键盘一笔画

一条不能断的线，走完键盘上的每一个键。

整个网站只有一块 3D 机械键盘（Three.js），它在每一屏扮演不同的角色：
首页里是背景和乐器，关卡里是棋盘，过关时是一场梦，终局是一座十四层的塔，
音乐模式里是一件有二十四种音色的乐器——还能整块沉进一只发光的水箱里弹。

## 运行

```bash
npm install
cp .env.example .env   # 填上 DeepSeek API key（过关时的那句话由它来写）
npm start              # 打开 http://localhost:3000
```

macOS 上也可以双击 `启动游戏.command`。

## 玩法

- 只能走上下左右紧挨着的键，每个键只能踩一次，把亮着的键全部走完。
- 一共 14 关，从 5 个键走到 40 个键；第 11 关加进数字排，第 12 关连 `; , . /` 一起。
- 第 8 关起必须停在指定的终点键上（终点要留到最后一步）。
- **第 13 关**：起点、终点都定死——F 和 T 斜对着，只差一步，却得绕完整块键盘才能回来（一共只有三种走法）。
- **第 14 关**：从 Q 出发，按顺序经过 W → O → R → L → D，最后停在 D 上。四十个键，只有一种走法。
- **提示**（`Enter`）：告诉你下一步走哪；已经走进死路的话，告诉你退回到第几步，再按一次直接帮你退。
- **跳过本关**：点两下确认，自动代走一遍；最后的塔里这一层会是一道虚影。

### 过关仪式：一场梦

1. **入梦**：最后一步落下，键盘的灯暗下去、光留下来——走过的线变成霓虹，页面背后浮出星云、星星和慢慢往上飘的光斑，
   偶尔划过一颗流星；音符后面拖出很长的尾音。
2. **彗星**：一颗亮点顺着整条线从起点跑到终点，一路撒星尘；经过哪个键，哪个键响一声、升起一道细光。镜头压低、跟着它慢慢摇过去。
3. **超新星**：到终点炸开——一团星尘、两圈彩虹色的冲击波荡满整块键盘，底下升起几枚星光烟花。
4. **浮起**：过关页上笔迹重新画一遍（笔尖撒着星星），然后整条离开键盘悬在上面，像萤火一样一直往外冒星点。
5. **拾字**：AI 写的那句话先只露出影子，每个词的首字母是一颗发光的光球，挂在它那颗键的上方——
   按下它（或者点它），键里升起一道光，字母拖着星尘飞回句子里，一个字母一个音。`空格` 全部放飞，`Enter` 直接下一关。
6. **成句**：整条线"呼"出一口星星，一道彩虹光扫过整句话，收一个和弦。

画面是一套只在仪式里才搭起来的后期：泛光 + 柔焦 + 一点色散，星尘是 GPU 粒子（运动全在着色器里算）；
浅色的键盘会压得更深，发光的线才显得出来。离开过关页后后期自己拆掉，平时的渲染一点不多花。
系统开了"减少动态效果"时整场梦都不演，只留最朴素的版本。

## 音乐模式

| 按键 | 作用 |
|---|---|
| 四排字母 / 数字键 | 琴键：往右高一级，往上高一个八度，A 那一排是中央八度 |
| `F1`–`F12` | 选乐器；`Caps Lock` 在 A / B 两组之间切换（共 24 件） |
| `←` `→`（或 `-` `=`） | 降调 / 升调（半音） |
| `↑` `↓` | 高八度 / 低八度 |
| `Shift` / `Option(Alt)` + 键 | 临时升 / 降半音 |
| 空格 / `Enter` | 延音踏板（按住 / 开关） |
| `Esc` | 返回（在深海里是浮上来） |

- **曲库**：内置 7 首，可以试听、跟弹、编辑、保存自己的曲子（自己存的曲子在浏览器里，不会丢）。
- **深海模式**（音乐模式右上角，或菜单里）：键盘沉进一只玻璃水箱——黑色背景，按下的键里升起荧光的气泡和烟雾，
  一根根光柱往上长，头顶的水面起涟漪、反光，键帽上晃着焦散的光纹；画面过一遍电影感的后期（泛光、隔着玻璃的折射和色散、暗角、颗粒）。

### 简谱记法

```
1–7 音级   0 休止   ^ _ 高/低八度   # b 升/降半音
-  延长一拍   /  时值减半   .  附点   |  小节线
( ) 圆滑线   ~ 延音线（同音连成一个长音）   { } 三连音
```

例：`(5 3/) 3/ ~ 3 0/. 2// | {1 2 3} 5 - -`

## 风格

顶栏的调色盘按钮：

- **情绪**（开心 / 悲伤 / 放松 / 紧张 / 忧郁 / 自由）：换音阶和灯光。音乐模式里整块键盘会换成对应的调式，比如悲伤是自然小调。
- **场景**（爱情 / 失恋 / 冒险 / 梦想 / 自然 / 城市 / 海洋 / 日落）：换键帽配色、背景粒子和环境声。
- **声音与画面**：混响、回声、画风（清澈 / 温暖 / 明亮 / 复古），以及氛围感、空间感、电影感、环境声、流光几个开关。
- **渐变**：每套配色都有一条渐变——键帽底光从左下铺到右上，走线从起点到终点顺着它换颜色，背景里有一圈同色的极光；
  打开「流光」，这些颜色会慢慢流动。
- **测一下声音**：弹一个和弦，从送往扬声器的那一路量电平，告诉你是浏览器把音频挂起了、音量是 0，还是一切正常。

## 声音检测

打开 `http://localhost:3000/soundcheck.html`：

- **实时自检**：输出电平表 + 音频状态。
- **响度平衡**：每件乐器离线渲染三种弹法，按 ITU-R BS.1770 量 LUFS。二十四件乐器已经按这个校准过（`js/audio.js` 里的 `LOUDNESS_TRIM`）。
- **频谱**：任意一件乐器、任意一种弹法画成频谱图。
- **像不像**：用 MFCC 和起音 / 衰减 / 亮度比较每两件乐器的音色。
- **延迟**：浏览器报的各段延迟（网页 + 限幅器 + 浏览器缓冲 + 系统和耳机），插拔耳机会自动刷新；
  再加一个"跟着节拍按空格"的实测——有线耳机测一次、蓝牙耳机测一次，两次的差就是蓝牙多出来的延迟。

### 耳机和延迟

从按下键到听见声音，网页自己只占不到 1 ms，限幅器固定 6 ms，浏览器缓冲几毫秒；剩下的全在系统和耳机：
外放、有线耳机一般加起来 30–50 ms，蓝牙耳机常常 150–300 ms——这是蓝牙本身的，网页没法让它变快。所以：

- 自动播放的东西（试听、深海演示、过关回放）会按测到的延迟让画面等一等，看到的和听到的对得上；
- 手上弹的没法让声音提前，检测到延迟明显偏大（多半是蓝牙）时会提示一次；想弹琴跟手，用有线耳机或外放。

## 目录

```
server.js                 Express 服务 + AI 造句接口（/api/generate）
public/index.html         页面结构
public/style.css          样式（颜色全部跟着当前键帽配色和它的渐变走）
public/script.js          游戏、过关仪式、音乐模式、风格和深海的界面
public/soundcheck.html    声音检测页
public/js/kb3d.js         3D 键盘引擎（按需渲染、自适应分辨率、渐变、后期接口）
public/js/audio.js        24 件合成乐器 + 效果链 + 场景环境声 + 响度校准
public/js/abyss.js        深海模式：水箱、气泡、烟雾、光柱、水面、焦散
public/js/dream.js        过关的梦境：泛光后期、星尘粒子、彩虹冲击波、光柱
public/js/dreamsky.js     梦境的天空（页面背景）：星云、星星、光斑、流星
public/js/post.js         泛光管线（深海和梦境共用）
public/js/colorways.js    36 套键帽配色（每套带一条渐变）
public/js/soundcheck.js   响度（BS.1770）、频谱、音色指纹
public/vendor/three/      Three.js r186（本地一份，不依赖 CDN）
```

需要支持 WebGL 2 的浏览器（新版 Chrome / Safari / Edge / Firefox）。

`/api/generate` 只收 1–12 个英文字母；同一个地址每分钟最多 30 次（超了用本地词库拼一句）；DeepSeek 20 秒不回就用兜底句。
放到公网上时，DeepSeek key 只在服务端的 `.env` 里，不会发到浏览器。
自测时在地址后面加 `?debug`，内部状态会挂到 `window.__ub` 上。
